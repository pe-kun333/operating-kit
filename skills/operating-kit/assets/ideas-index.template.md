## 案のカードの形

ワークフローの案は、生の案（`raw-R<周>.json`）の一件がそのままカードになる。主担当が足す案（先出しの案も。置き場・台帳から載せた案も）、関わり方 (B) の相談役が出した案、ワークフローを使わなかったときの案、段階②-2 で足す案は、この形で `cards.md` に書く（先出しの案は、ワークフローを起こす前に書いてコミットし、見立てより前の別コミットにする。`git log` で順番を確かめられる）。照らす・伸ばす・疑う相が空だったワークフローの案に主担当が補う照らしと疑いも、`cards.md` に同じ id の見出しで、補った欄だけを書く（`raw-R*.json` は直さない）（同じ観点の二周目も同じファイルに足す。周は id で分かる）。
